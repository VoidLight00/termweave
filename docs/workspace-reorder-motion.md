# 폴더 순서 변경의 움직임

## 사용자 요청

2026-10-12 사용자님께서 사이드바 손잡이로 폴더를 이동할 때, 잡은 폴더와 주변 폴더의 자리 이동이 보이도록 요청하셨습니다. 주변 폴더는 일정 지점까지 위치를 유지하다가 위아래로 자연스럽게 이동해야 합니다. 이 문서는 구현 방향과 참고 출처를 기록하며, 실제 검사 통과를 대신하지 않습니다.

## 구현 기준

- 손잡이에서만 끌기를 시작합니다. 접기·선택·이름 변경·메뉴의 독립 동작을 유지합니다.
- 잡은 폴더 전체가 포인터를 따라 이동합니다. 높이가 다른 폴더와 펼친 터미널 목록도 실제 크기로 계산합니다.
- 주변 폴더의 중간 지점을 충분히 넘으면 위치를 바꿉니다. 현재 구현은 6px 이동부터 끌기를 시작하고, 중간점에서 8px의 반전 여유를 두며, 주변 폴더 이동과 안착을 160ms로 처리합니다. 경계에서 앞뒤로 흔들리지 않도록 작은 여유를 둡니다.
- 드래그 중의 임시 배치와 서버에 저장하는 순서를 구분합니다. 놓을 때 기존 workspace.move 경로로 한 번만 저장합니다.
- 취소·연결 중단·구조 변경은 저장하지 않습니다. 실패한 저장은 기존 순서로 복구합니다.
- 움직임 줄이기 설정에서는 자리 이동을 즉시 표시합니다. 키보드 Alt+위/아래 동작을 유지합니다.

## 확인한 참고 구현

1. [SortableJS Animation.js](https://github.com/SortableJS/Sortable/blob/master/src/Animation.js): 이전·현재 사각형을 비교하여 변환 이동 후 제자리로 전환하는 방식입니다. [MIT 라이선스](https://github.com/SortableJS/Sortable/blob/master/LICENSE)는 2019년 Sortable 기여자를 저작권자로 표기합니다.
2. [dnd-kit](https://github.com/clauderic/dnd-kit): 드래그 중 보이는 요소와 목록 배치를 분리하는 구조를 참고합니다. [MIT 라이선스](https://github.com/clauderic/dnd-kit/blob/master/LICENSE)입니다.
3. [MDN Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events): 포인터 캡처·취소를 처리하는 브라우저 API를 참고합니다.

외부 구현의 동작 원리를 참고하여 기존 React 구조에서 직접 구현합니다. 외부 코드를 복사하거나 새 패키지를 설치하지 않습니다. 애플의 특정 알고리즘을 그대로 구현한다고 주장하지 않습니다.

## 검사

합성 폴더와 가짜 저장 응답을 사용하는 브라우저 검사에서 실제 마우스 이동, 폴더 따라오기, 주변 폴더 자리 이동, 취소, 저장 횟수, 실패 복구, 키보드 동작과 움직임 줄이기를 확인합니다. 운영 폴더 순서는 시험 목적으로 변경하지 않습니다.

2026-10-12 집중 검사에서 높이가 다른 폴더의 실제 마우스 이동, 임계점·반전 여유, 한 번의 저장·실패 복구, 취소, 상태 갱신 중 유지, 키보드·대기 요청 보호, 움직임 줄이기, 자동 스크롤과 손잡이 외 영역의 끌기 차단이 통과했습니다. Chromium과 합성 응답으로 검사했으며 Safari·물리 터치·운영 서버 저장은 미검증입니다. 전체 마스터 검사와 운영 준비 판정은 별도로 보고합니다.
