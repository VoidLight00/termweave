# TermWeave brand assets

The user selected proposal 04, Terminal Thread. The TermWeave mark connects a terminal prompt chevron to a W with an orange thread on a near-black field. It was generated specifically for this project with the image-generation tool on 2026-10-08, then exported at application icon sizes. It is separate from third-party agent identity marks.

## Files and uses

- `public/icons/termweave-v2-32.png`: browser favicon.
- `public/icons/termweave-v2-64.png`: application header and sidebar.
- `public/icons/termweave-v2-180.png`: Apple touch icon.
- `public/icons/termweave-v2-192.png`: web app and notification icon.
- `public/icons/termweave-v2-512.png`: installable web app icon.
- `public/icons/termweave-v2-maskable-512.png`: padded icon for platform masking.
- The 16 px and 1024 px exports support small-size inspection and future packaging.

Keep the complete mark and its internal spacing. Do not replace agent logos with the TermWeave mark. New artwork revisions must use a new filename so installed clients can invalidate cached images.

## Verification boundary

The brand and agent gallery was rendered with 52 agent marks, zero failed image loads and no horizontal overflow. App integration and browser refresh require separate release verification. An installed home-screen icon may remain cached by the operating system; desktop browser verification alone does not prove physical-device refresh.
