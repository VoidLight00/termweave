# Repository presentation references

Read-only README review; no code/assets copied or installation instructions executed.

- [WezTerm](https://github.com/wezterm/wezterm): separate installation, contribution and support channels; no guaranteed maintainer capacity. TermWeave separates quick start from detailed security/maintenance and does not promise response SLAs.
- [Alacritty](https://github.com/alacritty/alacritty): clear platform prerequisites and explicit non-goals such as built-in tabs/splits. TermWeave states native/backend and unsupported remote/Windows/manual-test limits explicitly.
- [tmux](https://github.com/tmux/tmux): precise supported-platform list, installation prerequisites and request to read issue guidelines. TermWeave supplies synthetic reproduction templates and distinguishes executed macOS checks from unexecuted Linux CI.

Popularity is not a functional benchmark or guarantee. These are presentation patterns independently implemented, not an endorsement or license to copy code or artwork.
