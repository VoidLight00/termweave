# TermWeave Android LTE 연결 계획

## 목적

USB, 같은 Wi-Fi, Tailscale 없이 Android 앱을 통해 맥북에서 사용자 소유 휴대폰의 화면을 보고 조작합니다. LTE 연결과 재부팅 후 무인 복구는 별개 요구사항입니다.

## 확인한 사실

- Samsung Android 16 실기에서 USB 및 주소를 명시한 Wi-Fi 화면 전송과 홈 입력을 확인했습니다.
- USB를 분리한 뒤 무선 디버깅 서비스가 사라졌으며, 케이블 없는 연결 유지는 확인하지 못했습니다.
- 현재 v0.2.5는 로컬 USB·Wi-Fi ADB 연결만 지원합니다. LTE 연결 앱은 아직 구현하지 않았습니다.
- Android 공식 문서에 따르면 MediaProjection 화면 공유는 각 세션마다 사용자 동의가 필요합니다. 잠금이나 프로세스 종료로 공유가 끝날 수 있습니다. 일반 앱에서 재부팅 후 자동 화면 공유를 보장하지 않습니다.

## 구현 전 결정

화면 공유를 시작하거나 재부팅 후 복구할 때 휴대폰에서 허용하는 방식으로 진행할지 사용자 응답을 기다립니다. 이전의 완전 무인 복구 조건을 임의로 완화하지 않습니다. 유료 중계 서버는 아직 신청하지 않습니다.

## 구성

1. Android 앱: 기기 등록, 명시적 공유 시작·종료, 실행 중 알림, 화면 캡처, 사용자 승인 접근성 서비스의 터치·스와이프·홈·뒤로 제어를 제공합니다.
2. 맥북: TermWeave의 등록 기기 화면에서 별도 제어 창을 엽니다. 휴대폰의 연결·공유·입력 허용 상태를 따로 표시합니다.
3. 인터넷 연결: 두 기기가 외부 서버에 먼저 연결합니다. 휴대폰에 ADB 포트를 공개하지 않습니다. 실시간 영상에는 WebRTC를 사용하며 직접 연결이 불가능한 통신망은 TURN 중계를 사용합니다.
4. 인증: 만료되는 등록 요청과 기기별 키를 사용합니다. 기존 TermWeave 전체 관리자 토큰을 휴대폰이나 중계 서버에 배포하지 않습니다. 해제한 기기는 즉시 차단합니다.
5. 연결 끊김: 전송이 끊기면 입력을 중단하고 재연결 상태를 표시합니다. 재연결 때 이전 터치나 클릭을 재전송하지 않습니다. 공유 권한이 끝나면 휴대폰 허용이 필요하다고 표시합니다.

## 완료 조건

- Wi-Fi와 USB를 모두 끈 실제 휴대폰에서 LTE 화면 프레임을 수신합니다.
- 맥북에서 터치·스와이프·홈·뒤로를 보내고 실제 결과를 확인합니다.
- 회전·연결 끊김·다시 연결·사용자 종료·권한 철회 시나리오를 확인합니다.
- 다른 계정·해제한 기기·만료된 등록 요청으로 연결할 수 없어야 합니다.
- 승인 방식으로 진행하면 재부팅 후 허용 안내와 복구를 확인합니다. 이를 완전 무인 복구라고 표기하지 않습니다.
- 실제 LTE 영상·입력 증거가 없으면 배포 여부와 관계없이 미완료로 보고합니다.
