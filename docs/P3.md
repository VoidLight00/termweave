# P3 격리·이식 회귀 검증

## 실행 경계

`scripts/verify-isolated.ts`는 매 실행마다 짧은 고유 임시 루트와 HOME/XDG/TMPDIR, named session socket, ephemeral HTTP ports, staging dist를 분리합니다. HERDR_TEST_LIVE와 inherited HERDR_SOCKET을 거부합니다. owned socket에만 종료를 요청합니다. 운영 세션·프로세스·설치본·공유 서비스를 변경하지 않습니다.

`scripts/browser.ts`는 explicit CHROME_PATH, Playwright Chromium, 플랫폼 system browser 순서로 확인합니다. 설치된 browser가 없으면 명시적 실패입니다. 모든 주요 browser regression은 공유 resolver를 사용합니다. private home QA 의존은 repository-owned source-style gate로 대체했습니다. 이 gate는 좁은 decorative status stripe 정책 검사이며 제품 visual quality 전체를 보장하지 않습니다.

## Canonical lane

```sh
bun scripts/verify-isolated.ts ledger type build unit integration render dock title-drag workspace move preview spatial ui source-style
```

명령별 실행 로그·exit·owned root·cleanup 결과는 ignored evidence에 있습니다. unit과 integration 파일 선택은 기존 canonical `scripts/ci-tests.ts`를 유지합니다. unknown 실패를 skip으로 숨기지 않습니다. 기존 플랫폼 제외 4개는 Linux `setsid` zombie·Windows 전용 등 조건이 명시된 inherited 검사입니다. macOS /proc 실패에는 동등한 explicit PID `lsof` 경로와 UTC `ps` 시작시각 검사를 추가했습니다.

## ACK lifecycle 경계

view unmount는 terminal subscriptions와 xterm handler를 즉시 제거합니다. 전송 완료된 request는 기존 connection만 ACK 또는 최대 기존 submit timeout까지 유지하며 결과 callback만 남깁니다. handler·terminal 입력·재접속·자동 재전송은 금지합니다. ACK/timeout/disconnect가 오면 연결을 닫습니다. duplicate ACK는 다시 draft를 settle하지 않습니다. composer draft store의 pane/machine key와 submission transaction을 유지하며 newer edits나 다른 workspace draft를 지우지 않습니다. 별도 ws unit은 drain/duplicate/disconnect/timeout을 검사하고 full master는 ACK before navigation·unmount 중·복귀 후·pending edits를 검사합니다.

## P2b 검토 보강

과거 P2b evidence는 삭제하지 않고 superseded로 기록합니다. 새 baseline/fixed execution-manifest는 fixture와 regression SHA-256을 각각 기록하며 동일 byte임을 확인합니다. observe/fixed 출력은 adopt 후 last-row/last-cell sentinel을 다시 출력하고 scroll 접근을 검사합니다. native lane은 body/stack/mount 수평·수직 containment까지 검사합니다. OwnedCleanup은 startup와 cleanup 실패 주입 시에도 독립적으로 모든 owned resource 정리를 시도합니다.

## CI와 미검증 한계

Linux/macOS CI는 contents:read, credential persistence off, full-SHA checkout/setup-bun만 사용하며 secrets·배포·remote dispatch가 없습니다. 현재 native runtime binary 승인 lock은 UNKNOWN입니다. 따라서 remote CI의 native/API/integration/browser-real lanes는 아직 검증하지 않았습니다. source/mock CI definition 작성은 Linux/macOS 실제 실행 PASS가 아닙니다. 실제 모바일/Safari/VoiceOver/실기기 IME와 다기기 shared geometry 경합도 남습니다. 제품 공개 privacy/license/install/release 게이트는 별도 단계입니다.
