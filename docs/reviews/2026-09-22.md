# Implementation review — 2026-09-22

The uncommitted chat interface and session-management work was preserved in
`c74d0f2`. The follow-up fixes address the following findings.

| Priority | Finding | Resolution and evidence |
| --- | --- | --- |
| P1 | Approval prompt IDs ignored command/plan bodies and option descriptions, allowing an old answer to match a different approval. | Hash parsed content before truncating its displayed body. Tests distinguish changed commands, including changes beyond the display cap, while keeping IDs stable across cursor movement. |
| P1 | A queued message auto-submitted when status became `blocked`, which can indicate an approval or question menu. | Auto-submit only at `idle` or `done`. Unit and real-browser tests confirm a blocked queue stays parked and later submits to its owning pane. |
| P1 | Switching panes during a multi-image upload let later files use the newly selected pane. | Capture the upload owner's pane and stop remaining uploads when its composer unmounts. The browser test delays a real upload, switches panes, and verifies no second upload or draft contamination. |
| P2 | JSON bodies such as `null` crashed mutation handlers; malformed identifiers, keys and image fields escaped validation. | Validate object bodies and field types before RPCs. HTTP contract tests cover nine mutation routes and malformed fields. Prompt-answer tests also cover non-string custom text and non-array selections. |
| P2 | File completion returned Git-quoted Unicode/newline paths and ignored Git exclusion rules when the cwd was a repository subdirectory. | Read NUL-separated Git paths and let Git discover the enclosing repository. Regression tests cover both cases. |
| P2 | New-session requests could be dismissed and restarted while pending; agent-start failure could create another workspace before an old timer selected the first one. | Keep pending creation visible; preserve the created pane on partial failure and offer Open session. Do not reset the form when another pane changes the default cwd. The browser test verifies pending dismissal is blocked and one workspace opens. |
| P2 | Agent arguments were accepted but discarded, and a slow startup could exceed the HTTP idle timeout. | Forward validated arguments and allow 75 seconds of HTTP inactivity for the 60-second agent startup. Use schema-generated agent types. |
| P2 | Unavailable localStorage crashed composer/queue initialization. | Fall back to in-memory state. A real mobile browser test disables storage reads and verifies the composer works. |
| P2 | `Mod+Shift+,` produced `<` on common keyboards and failed to open settings. | Recognize the physical Comma key. Unit and browser tests exercise the shortcut. |
