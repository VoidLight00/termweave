# TermWeave P2 원장 구현 기록

## 범위

P2는 요구사항·기능/출처/수용/실패 원장·schema·연결 validator·원장 테스트만 구현합니다. 기존 runtime 코드는 변경하지 않았습니다. 패키지 script에 Node 내장 모듈 기반 원장 명령 두 개만 추가했습니다. 제품 unit/integration/browser/build/설치·서비스·native·운영 PTY 검사는 실행하지 않았습니다. remote 생성·push·배포·재시작도 하지 않았습니다.

## 산출물

- `REQUIREMENTS.md`
- `docs/IMPLEMENTATION_PROMPT.md`, `docs/MAINTENANCE.md`, `docs/FAILURES.md`, `docs/P2.md`
- `tracking/features.json`, `tracking/acceptance.json`, `tracking/upstreams.json`, `tracking/failures.json`, `tracking/schema.json`

- `package.json`의 `validate:ledgers`, `test:ledgers`

기능 27개와 수용 검사 33개를 연결했습니다. 커스텀 docking·workspace·tab creation·native move·search·preview·focus·height CSS와 inherited auth/chat/remote/mobile/flow 경계를 포함합니다. 기존 시험 파일과 coverage gap을 구분합니다. 제품 verification은 모두 NOT_RUN이고 native-only 비필수 항목 하나는 NOT_APPLICABLE입니다.

## 관측과 lock

읽기 전용 GitHub API로 각 default branch의 SHA와 해당 revision의 README·LICENSE를 읽었습니다. 원격 소스는 실행하지 않았습니다. 관측 시점은 `tracking/upstreams.json`에 기록합니다.

| 대상 | 관측 revision | 승인 lock 경계 |
|---|---|---|
| herdr-web-ui | 6dc0db15e117fd8df8230bc3a6accae67b95f773 | 보존 source baseline 6bcb9bca4980b5a21b563dafac805a6a6c39ed61, 호환 UNKNOWN |
| herdr | 5da0a01e1eedda054db0c81dd3a780000c40d9f0 | runtime revision null, 미검증 |
| cmux | 21eb82f650c45595eb03bb0975c4ebb3ff17a176 | reference-only, 코드 import 없음 |

revision 고정 URL·line range·content SHA-256을 출처 원장에 저장합니다. GPL/BUSL 파일을 이식하지 않습니다. 새 기능 발견 규칙은 P4 watcher 구현 계약이며 현재 실제 schedule/후보 issue 실행은 없습니다.

## 검증 의미

`node scripts/validate-ledgers.mjs`는 schema·ID·안전 경로·code/test 존재·출처·cycle·미실행/evidence·license 경계·lock 분리를 검사합니다. `node --test scripts/ledger.test.mjs`는 오류 주입 fixture로 이 정책을 검사합니다. 두 검사의 성공은 **P2 원장만 PASS**입니다.

`node scripts/validate-ledgers.mjs --release-ready`는 현재 BLOCKED와 exit 2가 기대 결과입니다. feature 필수 미실행, 렌더링 미확정, compatibility UNKNOWN, PUB 공개 차단이 남기 때문입니다. 이것은 validator 자체의 실패가 아니라 공개 차단 정책의 동작입니다.

두 잘림 증상과 세 가설은 미확정으로 기록했습니다. PUB-001~010은 traceability ID로 연결했습니다. PUB-010 workflow disabled 상태는 활성 취약점과 구분합니다. loopback 기본값·auto-update OFF·존재하는 checksum·확정 secret 유출 미발견은 그대로 기록합니다. 최종 privacy clearance는 아직 없습니다.

실제 명령 output·exit code·파일 hash는 공개 Git에 포함하지 않는 로컬 evidence에 기록합니다. 공개 문서에는 개인 경로·실제 transcript·운영 screenshot을 넣지 않습니다. P2 결과로 공개나 운영 활성화를 허용하지 않습니다.
