# 모바일 관제·안드로이드·디자인 통합

## 범위와 판정

Tailscale 없는 USB·같은 Wi-Fi 미러링을 구현합니다. 외부 LTE에서 재부팅 뒤 폰을 만지지 않는 무인 복구는 별도의 실기 검증을 통과해야 합니다. 일반 Android 16의 MediaProjection은 세션별 승인이 필요하므로 LTE 본개발은 보류합니다. USB 미러링 성공을 LTE 무인 복구 성공으로 간주하지 않습니다.

## 새 기능

- 설정 → 내 안드로이드 기기: 기기 등록·해제, 명시적 Wi-Fi 페어링·접속, 일반·데이터 절약·폰 화면 끄기 미러링.
- 미러링은 서버 맥에서 열립니다. 하드웨어 식별값의 해시로 등록하며 USB·Wi-Fi가 바뀌어도 동일 기기로 처리합니다. 서버가 생성한 프로세스만 종료합니다.
- 무선 주소는 내부 IPv4만 허용합니다. 임의 명령과 공개 ADB 주소를 받지 않습니다. 폰 자체의 디버깅 승인 해제는 별도로 수행합니다.
- 응답 대기 목록과 빠른 검색에 P번호를 표시합니다. P번호 검색은 정확히 일치하는 기기 내 터미널만 반환합니다.
- 질문 응답은 표시 당시의 내부 터미널 ID를 추가로 확인합니다. 이전 클라이언트의 기존 질문 식별값 검증은 유지합니다.
- Catppuccin·Rosé Pine 밝은/어두운 테마, 직접 색상 설정, 글꼴 선택, 설정 가져오기·내보내기, 낮은 대비 안내를 제공합니다.
- JetBrains Mono·D2Coding·Noto Sans KR은 로컬 서버에서 제공합니다. 출처·원본 라이선스·해시는 public/appearance에 있습니다.

## Moshi 참고 기능 대조

공식 사이트: https://getmoshi.app/ · 공개 GitHub 연결은 설치용 Homebrew tap입니다. 앱 소스를 공개 라이선스로 제공한다는 근거가 없으므로 앱 코드·이미지는 복제하지 않습니다.

| 기능 | TermWeave 적용 |
|---|---|
| 터미널 빠른 이동 | 기존 검색에 정확한 P번호 검색과 표시를 추가합니다. |
| 전체 테마·폰트 | 오픈소스 테마와 로컬 글꼴, 사용자 색상 설정을 추가합니다. |
| 채팅·질문·여러 줄 입력 | 기존 conversation, prompt, 입력 확인 기능을 재사용하고 터미널 대상 검증을 강화합니다. |
| 에이전트 상태·알림 | 기존 NeedsInput 및 push 정책을 유지하며 P번호로 대상을 식별합니다. |
| 단축키·저장 문구 | 기존 shortcutOverrides와 quickReplies를 재사용합니다. |
| 파일·이미지 전송·음성 | 기존 기능을 유지합니다. 이미지 주석·완전 로컬 음성 인식은 이번에 새로 구현하지 않았습니다. |
| SSH·Mosh·ET | 기존 SSH 기기 연결을 유지합니다. 브라우저 WebSocket을 Mosh/ET라고 표시하지 않습니다. |
| Face ID·Apple Watch | 웹 앱과 Android의 기능으로 간주하지 않습니다. |
| 앱 복귀 | 기존 재접속을 유지합니다. 서버·맥 재부팅 후 명령 실행 복구는 보장하지 않습니다. |

## 검증

`gates/android_gate.sh`는 등록·식별·중복 실행·개별 종료·잘못된 주소·조회 전용·테마 데이터 및 폰트 출처 무결성을 검사합니다. 이 테스트는 실제 무선 연결·LTE·재부팅·물리 모바일 렌더링을 대신하지 않습니다.
