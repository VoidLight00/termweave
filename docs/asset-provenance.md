# Asset provenance and redistribution boundary

`public/icons/termweave.svg` is an independently authored geometric terminal-grid icon created for this project. No cmux or inherited ram artwork was copied. Its source is text, reviewed under the repository MIT license.

Inherited raster artwork, social previews and fixture video are not approved for the first public source snapshot. They must be excluded from the publication tree and reachable public history; merely removing active references is insufficient. Their old local history is preserved for audit, not published.

The Nerd Font glyph subset retains original attribution and SIL OFL notices in THIRD_PARTY_NOTICES. Dependency licenses and bundled font source/checksum mapping require final inventory validation. Native herdr remains a separate Apache-2.0 runtime and is not redistributed. TermWeave remote runtime bundles are unsupported and no default upstream executable bundle is downloaded.

Release manifests and retained digest sidecars are trusted local metadata, not signatures. Owner-level filesystem compromise can rewrite metadata and bytes. Bounds, symlink refusal and exact-byte digest checks protect ordinary invalid candidates and accidental mutation; they are not hostile-owner authentication.
